# Multistream Tools desktop app

Downloads for the [Multistream Tools](https://multi.mhy.io) desktop app: a small tray app for Windows, macOS and
Linux that does the parts of Multistream Tools that need your PC.

- **OBS & Streamer.bot**: runs your chat bot's, rewards' and the Stream manager's scene switches, sources, mutes and
  Streamer.bot actions, without a dock in OBS.
- **Now playing**: sends what your music plays, for `!np` in chat and the Now playing overlay.
- **Visualizer**: bars and a glow on the Now playing overlay that move with your music. The sound never leaves your
  PC: only its levels go to OBS.
- **Stream health**: shares OBS's stats while you're live, if you turn it on.

It sits in the tray, starts with your computer and updates itself.

## Download

Get the newest version under [Releases](../../releases/latest):

| System | File |
| --- | --- |
| Windows 10/11 | `Multistream-Tools-Setup-<version>.exe` (or the Microsoft Store version, once it's listed) |
| macOS (Apple silicon) | `Multistream-Tools-<version>-arm64.dmg` |
| macOS (Intel) | `Multistream-Tools-<version>-x64.dmg` |
| Linux | `Multistream-Tools-<version>-x64.AppImage`, or `…-x64.deb` for Debian and Ubuntu |

The Windows installer and the Mac app aren't signed yet:

- **Windows**: if it says "Windows protected your PC", click **More info → Run anyway**.
- **macOS**: right-click the app → **Open**, then **Open** again (only the first time).

Then click **Link this PC** in the app and allow it in your browser.
